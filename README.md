# AlzCare AI

**An AI-Powered Early Alzheimer's Detection & Cognitive Assistance Platform using Deep Learning**

A full-stack MERN application that combines a Convolutional Neural Network for MRI-based
risk prediction with cognitive screening tests and daily assistance tools — connecting
patients, caregivers, and doctors on a single role-based platform.

> **Academic Disclaimer:** This system is a final year major project built for academic
> purposes. It is a decision-support tool and does **not** replace professional medical
> diagnosis.

---

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | ReactJS 18, React Router DOM v6, Axios, CSS3 |
| Backend | Node.js, Express.js 4 |
| Database | MongoDB Atlas, Mongoose |
| Authentication | JWT, bcrypt, Role-Based Access Control |
| Media Storage | Cloudinary |
| AI Service | Python, Flask / FastAPI, TensorFlow / Keras (CNN) |
| Build Tool | Vite |

---

## Modules

1. **Patient** — Cognitive tests, MRI upload, reminders, memory support
2. **Caregiver** — Patient monitoring, routine management, risk alerts
3. **Doctor** — AI result review, clinical remarks, report generation
4. **Admin** — User & role management, model monitoring, analytics
